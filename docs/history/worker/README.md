# سابقهٔ گام‌های مهاجرت Worker

گزارش‌های این پوشه بر اساس تاریخ و شناسهٔ گام نام‌گذاری شده‌اند. هر گزارش دامنهٔ تغییر، آزمون‌های همان اجرا و محدودیت‌ها را نگه می‌دارد.

برای وضعیت جاری از [راهنمای مهاجرت](../../../migration/README.md)، [progress.json](../../../migration/progress.json) و [ماتریس آزمون](../../../migration/QA-MATRIX.md) استفاده کنید. مسیرهای داخل متن تاریخی یا JSONهای قدیمی ممکن است محل زمان اجرای آن گزارش را بیان کنند؛ جدول [جابه‌جایی‌ها](../../project/relocations.json) مسیر کنونی آن‌ها را مشخص می‌کند.
