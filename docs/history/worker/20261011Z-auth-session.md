## مسئله و تصمیم

GET هویت از قبل حساب رسمی Site را به کاربر و عضویت D1 نگاشت می‌کرد، اما writeها هنوز نشست عملیاتی اصلی را الزام نمی‌کردند. ستون `active_session_hash` در کاربر وجود داشت، ولی جدول رخداد نشست و POST/DELETE معتبر برای حفظ قاعده legacy یک نشست فعال وجود نداشت.

این مرحله بدون ساخت ورود مستقل یا OAuth، همان هویت Site را مرجع ورود نگه داشت و یک cookie عملیاتی جدا ساخت. مقدار خام نشست فقط در cookie امن، HttpOnly و SameSite=Strict قرار می‌گیرد؛ D1 فقط SHA-256 آن را نگه می‌دارد. مدیر مرکزی مطابق قاعده مرجع از hash شعبه‌ای معاف است. GET هویت و GET CSRF عمداً پیش از نشست باقی ماندند تا آغاز نشست ممکن باشد؛ مسیرهای داده منتقل‌شده پس از آن نشست معتبر را لازم دارند.

## تغییرات

- migration append-only نهم برای جدول `tamiran_user_session_events` با scope، FK، enum و indexهای مرجع افزوده شد.
- POST `/api/auth.php` با action ثابت `begin_site_session`، JSON محدود، same-origin و CSRF وابسته به هویت Site پیاده شد.
- DELETE `/api/auth.php` خروج شرطی و idempotent را پیاده کرد؛ cookie قدیمی نمی‌تواند نشست جدیدتر را پاک کند.
- ورود دوم با compare-and-swap نشست قبلی را لغو و رخدادهای `revoked` و `login` را اتمیک ثبت می‌کند؛ race یا شکست رخداد بدون تغییر ناقص rollback می‌شود.
- settings، catalog، operations، capabilities، جست‌وجوی مشتری، پیش‌نویس و create/PATCH پرونده اکنون در wiring تولیدی نشست عملیاتی معتبر لازم دارند.
- adapter رابط، بازیابی نشست را به GET هویت سپس POST آغاز نشست و خروج را به DELETE سپس sign-out رسمی Site متصل کرد.
- فقط `app/tamiran/directadmin-api.ts` از ۱۹ فایل frozen عمداً تغییر کرد؛ hash manifest بازتأیید شد و ۱۸ فایل دیگر و ۲۰ منو ثابت ماندند.

## محدودیت‌ها و ادعای ممنوع

- API و D1 میزبانی‌شده اجرا نشدند؛ کلید runtime نیز تنظیم یا آزموده نشده است.
- مرورگر در محیط حاضر در دسترس نبود؛ هیچ ادعای E2E یا مشاهده DOM وجود ندارد.
- انقضای idle/absolute و ابطال ناشی از تغییر اعتبارنامه هنوز منتقل نشده‌اند؛ cookie فعلی session cookie با اعتبار رمزنگاری‌شده هشت‌ساعته برای CSRF است، نه اثبات تکمیل سیاست انقضای نشست.
- خطاهای lint قدیمی رابط frozen همان baseline باقی ماندند.
- root منتشرشده همچنان گزارش/دموی static است؛ Candidate Worker عملیاتی deploy نشده است.
- این checkpoint به معنی صفر باگ، تکمیل انتقال یا آمادگی پایلوت نیست.
