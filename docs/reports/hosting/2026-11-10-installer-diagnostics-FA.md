# تشخیص امن خطای نصب

پیام قبلی برای خطای SQL، ساخت مدیر و انتشار فایل تنظیمات یکسان بود و تشخیص علت را ناممکن می‌کرد. نصب‌کننده اکنون پیش از اجرای SQL امکان ساخت و انتشار امن فایل با hard link را در پوشه private امتحان می‌کند و فایل‌های آزمایشی را پاک می‌کند. در صورت محدودیت link یا دسترسی فایل، پیش از ساخت هر جدول متوقف می‌شود. برای خطای پس از آغاز ساخت، فقط مرحله، شماره دستور و SQLSTATE/کد عددی دیتابیس، یا کد امن خطای انتشار config نمایش داده می‌شود؛ پیام خام، متن SQL، مسیر و مشخصات اتصال نمایش داده نمی‌شوند.

۳۳ بررسی نصب‌کننده، ۱۴ بررسی HTTP امنیتی و آزمون با تابع link غیرفعال موفق بودند. در MariaDB محلی، نصب کامل ۱۰۴ جدول موفق و خطای محدودیت TRIGGER روی دیتابیس جدا بازآفرینی شد؛ ۳۵ جدول ناقص حفظ شدند، config فعال نشد و کد امن نمایش داده شد. نصب از ZIP با فرم HTTP واقعی و دیتابیس خالی نیز موفق و نصب‌کننده قفل شد. ریشه خطای هاست کاربر هنوز مشخص نشده و این تغییر رفع قطعی مشکل خاص آن هاست را اثبات نمی‌کند.
