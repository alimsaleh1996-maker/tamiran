# پوشش ثبت رویداد نسخه PHP

ثبت ساختاریافته پاسخ‌های موفق و ناموفق همه endpointهای API نسخه PHP، از جمله سه مسیر محتوای باینری، با شناسه درخواست، endpoint، وضعیت و مدت اضافه شد. خطاهای سرور کلاس استثنا، فایل، خط و در خطای PDO کد امن را نگه می‌دارند؛ متن خام استثنا و SQL ثبت نمی‌شود. رویدادهای کسب‌وکار و ممیزی پیشین حفظ شدند. نام مسیر بدون query ثبت می‌شود.

برای نصب، بدون نیاز به config و بدون ثبت رمز یا متن SQL، نتیجه و مرحله و کد امن ثبت و شناسه روی پیام خطا نمایش داده می‌شود. رابط برای خطای اجرا، promise، rendering، قطع درخواست و خطای بارگذاری عملیات، گزارش محدود و best-effort شامل نوع و شناسه و در صورت امکان نام endpoint می‌فرستد؛ متن خطا، stack، اطلاعات فرم و URL کامل ارسال نمی‌شود. خطای بارگذاری عملیاتی بدون کد سرور، شناسه بررسی UI نشان می‌دهد. گزارش مرورگر در سرور به ۱۰ گزارش در ۱۰ دقیقه برای هر نشست محدود است.

فایل جدید با umask خصوصی ایجاد می‌شود. داده‌های حساس بر اساس کلید، متن‌های آزاد خطا و دلیل و نام متنی actor از لاگ فایل پنهان می‌شوند؛ این کنترل، پاکسازی کامل هر اطلاعات شخصی ممکن در رویدادهای قدیمی یا شناسه‌های کسب‌وکار را تضمین نمی‌کند. اگر لاگ قابل نوشتن نباشد، عملیات متوقف نمی‌شود و پیام عمومی بدون داده به PHP error log می‌رود. ثبت هر پاسخ، مصرف فضای دیسک را افزایش می‌دهد؛ حذف/چرخش خودکار فعال نشده است.

## شواهد

- ۱۲۸ بررسی HTTP واقعی محلی شامل کنترل کیفیت، مالی و تحویل؛ ۳۷ بررسی مرورگر شامل قطع عملیات، ارسال گزارش و تطبیق شناسه قابل مشاهده با لاگ.
- تست مستقل مرورگر برای error event، ۲۰۰ و ۴۰۱ واقعی، کنترل مبدا، ورودی غیرعادی و حذف داده مصنوعی از لاگ؛ تست خطای ۵۰۰ و شکست ذخیره لاگ.
- نصب‌کننده: ۳۶ بررسی با link فعال و ۳۶ با link غیرفعال، ۱۶ بررسی HTTP؛ بازآفرینی خطای مجوز SQL در دیتابیس مجزا با حفظ ۳۵ جدول ناقص، عدم انتشار config و بدون انتشار رمز در لاگ.
- اجرای محلی ۱۰۰۰ پرونده: ۱۳٫۳۴ ثانیه ساخت و میانه خواندن صفحه اول ۲۴٫۴ میلی‌ثانیه؛ ظرفیت هاست واقعی نیست. TypeScript، ساخت frontend، پنج قرارداد frontend و دو آزمون بسته موفق شدند.

## محدودیت

نسخه PHP مورد استفادهٔ کاربر پوشش داده شده است؛ Worker در حال مهاجرت و دموی ثابت، runtime مستقل‌اند و در این تغییر دست‌کاری نشده‌اند. خطای وب‌سرور یا PHP قبل از بارگذاری bootstrap، قطع کامل شبکه، ورود به برنامه پیش از اجرای JavaScript و لاگ‌نویسی ناموفق ممکن است فقط در PHP/web server یا مرورگر دیده شوند. بررسی عملی هاست و استقرار انجام نشده است.
