# ساختار و مسیرهای اصلی تعمیران

نسخهٔ قابل نصب **PHP/MySQL** در `hosting/` است. برای اصلاح برنامه از این پوشه شروع کنید؛ مرجع PHP منجمد در `migration/worker/baseline/` برای مقایسه نگه داشته شده است.

```text
tamiran/
├── hosting/                 نسخهٔ قابل نصب روی هاست
│   ├── public_html/         فایل‌های عمومی و API
│   ├── private/             سرویس‌های خصوصی و schema.sql
│   ├── frontend/            سورس قابل ویرایش رابط
│   ├── tests/               آزمون‌های محلی و مصنوعی
│   └── scripts/             بسته‌بندی نسخهٔ نصب
├── docs/
│   ├── project/             ساختار و فهرست جابه‌جایی‌ها
│   ├── ruflo/               روش اجرای مراحل توسعه
│   ├── reports/hosting/     بررسی‌ها و تصاویر نسخهٔ PHP
│   ├── reports/worker/      بررسی‌های Worker
│   └── history/worker/      گزارش گام‌های گذشتهٔ مهاجرت
├── graphify-out/            نقشهٔ خلاصه، گراف کامل و دادهٔ روابط
├── scripts/                ابزارهای نگهداری و ساخت نقشه
├── tests/                  آزمون‌های ابزارها و حفاظت ساختار
├── workflows/              تعریف مراحل و قالب خروجی
├── migration/worker/       مهاجرت جداگانهٔ Worker و مرجع منجمد
└── dist/                   دموی قدیمی Sites
```

| کار | فایل یا پوشهٔ مناسب |
|---|---|
| اصلاح صفحه‌ها و فرم‌ها | [رابط PHP](../../hosting/frontend/src/app/tamiran) |
| درخواست‌ها و مجوزهای سرور | [API](../../hosting/public_html/api) |
| سرویس‌ها، گردش تعمیر و SQL | [بخش خصوصی](../../hosting/private) |
| نصب و ارتقای هاست | [نصب](../../hosting/INSTALL-FA.md) و [ارتقا](../../hosting/UPGRADE-FA.md) |
| ساخت بسته | [اسکریپت بسته‌بندی](../../hosting/scripts/package.py) |
| بررسی‌های گذشته | [فهرست مستندات](../README.md) |

گزارش‌ها از کنار سورس اجرایی به دسته‌های مستندات منتقل شده‌اند. فهرست مسیرهای قدیم و جدید همراه checksum در [relocations.json](relocations.json) است. محتوای تصاویر و JSONهای تاریخی حفظ شده؛ لینک‌های نسبی گزارش‌های Markdown برای محل جدید اصلاح شده‌اند.

ساختار `public_html` و `private`، مسیرهای API، SQL، خروجی قابل نصب، مرجع منجمد و تنظیمات Site ثابت هستند. این نوبت نظم‌دهی، بازنویسی منطق کسب‌وکار نیست.

نقشهٔ جدید ابتدا بخش‌های نسخهٔ PHP را نشان می‌دهد. می‌توانید یک بخش، فایل و سپس نماد را باز کنید. Worker، ابزارها، اسناد و مرجع منجمد نمای جدا دارند. نمای کاملِ متراکم هم برای بررسی تخصصی در فایل جدا حفظ شده است.
