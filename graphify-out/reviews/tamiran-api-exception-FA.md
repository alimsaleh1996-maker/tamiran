`22d12691c79aba832ab5acc2eba4e9286e459cdafa4711d88ca4e68516ec6b1f`

**هر ۳۲۳ رابطهٔ استنباطی به این کلاس، در سورس تأیید شد.** در هر مورد، عبارت واقعی `new TamiranApiException(...)` در خط ثبت‌شده، داخل همان تابع/متد/closure و در همان نسخهٔ پروژه وجود دارد. هیچ رابطهٔ نامطمئن یا اشتباهی در این مجموعه باقی نماند. این نتیجه به معنای اجرای آن شاخه در هر درخواست یا تأیید امنیت همهٔ APIها نیست.

## روش بررسی

پرس‌وجو از گراف موجود و با واژه‌های همان گراف، یعنی `tamiran`، `api` و `exception`، شروع شد. سپس ۹۵ فایل PHP با tree-sitter-php تجزیه شدند؛ هیچ خطای تجزیه گزارش نشد. برای هر رابطه، محل ساخت شیء، نام و خط شروع callable، نسخهٔ مبدأ/مقصد و نبود ابهام namespace کنترل شد. سه نام نمایشی کوتاه `.lookup()`، `.request()` و `.send()` متعلق به متدهای `TamiranKavenegarProvider` نیز با نام متد و محل تعریفشان تطبیق داده شدند.

همهٔ ۳۲۳ رابطه از callable به کلاس می‌روند. این‌ها فراخوانی سازندهٔ کلاس‌اند؛ برچسب عمومی `calls` به معنی ساخت خطای سفارشی است و لزوماً فراخوانی یک سرویس دیگر نیست. برچسب `INFERRED` و امتیاز 0.85 در گراف، خروجی حل‌کنندهٔ خودکار بوده است. برای حفظ منشأ، گراف اصلی و برچسب‌هایش تغییر نکردند؛ تأیید مستقل در JSON این بررسی ثبت شده است.

## معنای نقش مرکزی کلاس

کلاس در [bootstrap.php:6](../../hosting/public_html/api/bootstrap.php#L6) تعریف شده، `RuntimeException` را گسترش می‌دهد و یک `httpStatus` با پیش‌فرض 400 دارد. این کلاس قالب مشترک خطاهای اعتبارسنجی، دسترسی و عملیات است؛ تعداد زیاد وابستگی‌ها برای چنین نقشی غیرمنتظره نیست.

نمونه‌های بررسی‌شده:

- [bootstrap.php:665](../../hosting/public_html/api/bootstrap.php#L665): نبود actor به خطای 401 منجر می‌شود؛ الزام تغییر رمز اولیه در خط 668، خطای 403 می‌سازد.
- [v2-core.php:33](../../hosting/private/v2-core.php#L33): رد مجوز V2، سازندهٔ خطای 403 را فراخوانی می‌کند.
- [backup-engine.php:128](../../hosting/private/backup-engine.php#L128): درخواست ساخت بکاپ در تراکنش باز، خطای 409 می‌سازد.
- [bootstrap.php:748](../../hosting/public_html/api/bootstrap.php#L748): `tamiran_fail` وضعیت خطای سفارشی را می‌گیرد؛ برای وضعیت‌های 5xx متن عمومی می‌فرستد و جزئیات را در مسیر log قرار می‌دهد. این توصیف خواندن سورس است و آزمون HTTP تازه نیست.

برچسب اجتماع گراف برای کلاس فعلی `PHP Product Provisioning` است، اما محل تعریف و نقش آن عمومی است. اجتماع بر اساس الگوی اتصال تعیین شده؛ از آن نباید مالکیت کلاس توسط زیرسامانهٔ فروش یا محصول را نتیجه گرفت. تعریف منجمد نیز کلاس نسخهٔ دیگری است؛ هم‌نامی به معنی وابستگی اجرایی میان دو نسخه نیست.

## محدودیت پوشش گراف

در دو نسخه، ۱٬۲۷۳ محل ساخت این خطا پیدا شد. همهٔ ۳۵۹ callable دارای چنین ساختی در گراف رابطه دارند: ۳۲۳ رابطهٔ استنباطی بررسی‌شده و ۳۶ رابطه‌ای که از ابتدا `EXTRACTED` بودند. یک رابطه ممکن است چندین محل خطا در همان callable را نمایندگی کند.

با این حال، **۳۷ محل ساخت در بدنهٔ اصلی شش فایل، خارج از callable، به‌عنوان رابطهٔ calls مدل نشده‌اند**:

| فایل | محل‌های ساخت در سطح اصلی فایل |
|---|---:|
| `hosting/public_html/api/backup-download.php` | ۴ |
| `hosting/public_html/api/captcha.php` | ۴ |
| `hosting/public_html/api/files-v2.php` | ۱۳ |
| `migration/worker/baseline/api/backup-download.php` | ۴ |
| `migration/worker/baseline/api/captcha.php` | ۱ |
| `migration/worker/baseline/api/files-v2.php` | ۱۱ |

این یک محدودیت استخراج گراف است؛ به معنی نبود مدیریت خطا در برنامه نیست. برای مثال [backup-download.php:21](../../hosting/public_html/api/backup-download.php#L21)، [captcha.php:52](../../hosting/public_html/api/captcha.php#L52) و [files-v2.php:16](../../hosting/public_html/api/files-v2.php#L16) در سورس `Throwable` را به `tamiran_fail` می‌رسانند. موارد غایب و محل دقیق سطر/ستون در JSON ثبت شده‌اند؛ در این بررسی رابطه‌ای به گراف افزوده نشده است.

## مسیرهای جداگانهٔ پاسخ HTTP — Bypasses

جست‌وجوی literalهای مربوط به پاسخ HTTP، دو ورودی وب بدون رابطهٔ مستقیم با این کلاس نشان داد:

- [public_html/index.php:13](../../hosting/public_html/index.php#L13): ورودی HTML هنگام رد اتصال، پاسخ متنی 426 می‌دهد. این مسیر فرم مرورگر است.
- [public_html/install/index.php:34](../../hosting/public_html/install/index.php#L34): نصب‌کنندهٔ مستقل پیش از آماده‌شدن تنظیمات، خطاهای فرم و `TamiranInstallException` را با وضعیت HTTP و صفحهٔ HTML مدیریت می‌کند.

router توسعه و چند محافظ CLI تست نیز پاسخ مستقیم دارند؛ آن‌ها API تجاری نیستند. تفاوت این مسیرها با خطای JSON معمول API به‌تنهایی باگ محسوب نمی‌شود. بررسی آن‌ها در دادهٔ ماشین‌خوان از همسایه‌های عادی کلاس جدا شده است.

## بازتولید و حدود نتیجه

```sh
# از ریشهٔ مخزن، با Python همان محیطی که Graphify در آن نصب است:

```

[اسکریپت بررسی](verify_exception_edges.py) کد PHP را اجرا نمی‌کند و به شبکه، دیتابیس، پیامک یا هاست متصل نمی‌شود. [JSON جزئیات](tamiran-api-exception.json) برای هر ۳۲۳ رابطه، شاهد، مبدأ، خط و هش فایل‌های بررسی‌شده را دارد. اگر سورس یا گراف تغییر کند، نتیجه باید دوباره تولید شود.

کد برنامه، SQL، مرجع منجمد و گراف اصلی دست‌نخورده‌اند. این نتیجه محدود به صحت ایستای روابط این کلاس و پوشش استخراج است؛ مجوز تغییر محصول یا گواهی کامل امنیت/رفتار API از آن استنباط نمی‌شود.
