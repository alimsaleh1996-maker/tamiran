# آزمون‌های قبض پذیرش 1.0.0-rc.13

- ۱۸۴ بررسی API و مرورگر Chromium در PHP/MariaDB محلی، ۲۸ تست Node و ۲ تست بسته‌سازی موفق بودند. TypeScript، Build و نحو فایل‌های PHP تغییرکرده نیز بررسی شدند.
- در پروندهٔ مصنوعی چندایرادی، برآورد اولیه، سقف توافق‌شده و پیش‌پرداخت جداگانه نمایش داده شدند. مجوز دریافت اطلاعات قبض، پنهان‌سازی شناسه‌ها، حذف یادداشت داخلی و نمایش پیش‌نمایش در موبایل بررسی شدند.

- ارتقا از `rc.12` به `rc.13` در نصب محلی با حفظ نشست مدیر، تعمیرگاه‌ها و تنظیمات خصوصی تأیید شد.
