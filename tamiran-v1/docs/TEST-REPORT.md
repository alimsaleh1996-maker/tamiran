# آزمون‌های نسخهٔ توسعه

## 1.0.0-rc.6 — صف مالی در نشست قدیمی یا ماژول غیرفعال

- مرورگر با اطلاعات نشست فاقد ماژول مالی و مجوز فعال در سرور، همچنان صف و پروندهٔ آزمایشی را نشان داد. روال صدور فاکتور، تسویه و تحویل جداگانه اجرا شد.
- در محیط آزمایشی، مدیر با ماژول غیرفعال پروندهٔ منتظر و مسیر فعال‌سازی را دید. صدور از API با ۴۰۳ رد شد و کاربر فاقد مجوز به صف دسترسی پیدا نکرد. پس از فعال‌سازی، همان پرونده در پیش‌نویس‌ها ظاهر شد.
- TypeScript، Build، PHP lint، آزمون‌های Node و رگرسیون گردش‌کار و پذیرش در محیط محلی اجرا شدند. نصب تازه و ارتقا از `rc.5` در محیط جداگانه بررسی شدند.

## 1.0.0-rc.5 — نمایش پرونده در صف مالی

- مرورگر از ورودی معمول «مالی و تحویل»، صف مالی را برای مدیر باز کرد. آزمون همان پروندهٔ مصنوعی را فقط از فهرست عمومی حذف کرد و همچنان آن را در صف مالی و در جست‌وجوی شمارهٔ رسید و موبایل یافته است.
- صدور فاکتور، ثبت تسویه، انتخاب صف تحویل، تازه‌سازی صفحه و تحویل واقعی جداگانه بررسی شدند.
- TypeScript، Build، PHP lint، رگرسیون گردش‌کار و پذیرش، آزمون‌های Node و بسته‌بندی اجرا شدند. نصب تازه و ارتقا از `rc.4` در محیط مستقل PHP/MariaDB بررسی شدند.

## 1.0.0-rc.4 — تأمین قطعه، مدیریت، کنترل کیفیت و تحویل

- پروندهٔ مصنوعی Pro در PHP/MariaDB و Chromium بررسی شد. سفارش بدون درخواست، درخواست نامرتبط، تخصیص مازاد و سفارش باز تکراری رد شدند. دریافت جزئی یک قطعه برای دو پرونده، دریافت معیوب و تلاش مجدد بررسی شدند.
- صف تأمین از ردیف درخواست پرونده سفارش می‌سازد. دسترسی مدیر به تخصیص، تصمیم ارجاع، پیگیری و گزارش از صفحات مرتبط بررسی شد.
- کنترل کیفیت و تحویل در عرض‌های ۳۲۰، ۳۹۰، ۷۶۸ و ۱۴۴۰ پیکسل بررسی شدند. پیش‌نویس QC پس از تازه‌سازی بازیابی شد. روی پروندهٔ مصنوعی، صدور فاکتور و تسویه ابتدا وضعیت آمادهٔ تحویل را ثبت کردند و تحویل واقعی جداگانه ثبت شد.
- ۱۳۶ بررسی گردش‌کار، ۲۳ بررسی رگرسیون پذیرش، ۴۶ بررسی مرورگر مدیر، ۲۸ آزمون Node و دو آزمون بسته‌بندی اجرا شدند. TypeScript، Build و PHP lint موفق بودند. هشدار اندازهٔ باندل Vite باقی است.
- نصب تازه و ارتقا از `rc.3` در محیط محلی مستقل بررسی شدند. هیچ درخواست آزمایشی به سرویس پیامک، درگاه واقعی یا هاست عملیاتی ارسال نشد.

## 1.0.0-rc.3 — تطبیق پنل تکنسین با نمونهٔ نسخهٔ هفتم

- ۹ بررسی بصری و رفتاری با Chromium روی پنل واقعی PHP/MariaDB موفق بود. کارتابل، عیب‌یابی، عملیات تعمیر و رسید ارجاع در عرض‌های ۳۲۰، ۳۹۰، ۷۶۸ و ۱۴۴۰ پیکسل بررسی شدند. تصاویر کنارهم پس از مقایسه با HTML تأییدشده تهیه شدند.
- ۶۸ آزمون مرورگر تکنسین و ۴۶ آزمون مرورگر مرکز عملیات موفق بودند. موارد کلیدی شامل حفظ پیش‌نویس و پیوست، ثبت دقیقاً یک‌بار پس از قطع پاسخ، تعیین تکلیف قطعه، گزارش مغایرت و جلوگیری از انتقال پیش از تأیید مقصد بودند.
- ۱۳۶ بررسی گردش‌کار، ۵۱ بررسی API تکنسین، ۳۹ بررسی فرایندهای نسخهٔ هفتم، ۳۵ بررسی شناسهٔ دستگاه و ۲۳ بررسی رگرسیون پذیرش موفق بودند.
- TypeScript، Build، بررسی نحو PHP در کانتینر، ۲۸ آزمون Node و دو آزمون بسته‌بندی موفق بودند. هشدار اندازهٔ باندل Vite باقی است.
- نصب تازه و ارتقا از `rc.2` در محیط مصنوعی بررسی شدند. نسخهٔ فرانت‌اند و بک‌اند، سلامت API و حفظ پرونده و تنظیمات پیشین پس از ارتقا بررسی شد. بررسی پذیرش، هاست یا سرویس واقعی پیامک و پرداخت روی محیط عملیاتی در این مرحله انجام نشد.

## 1.0.0-rc.2 — صف پیگیری و بازکاری

- ۴۶ بررسی نسخهٔ هفتم با HTTP و Chromium موفق بود. چهار بررسی تازه، مسیر انتخابی بازکاری، پیدا شدن پروندهٔ گذشته از موعد، حفظ علت پیگیری پس از ثبت یادداشت و کنترل مجوز صف مدیر را پوشش دادند. گزارش عملکرد، موعد اولیه و زمان انتقال را از دادهٔ ثبت‌شده گزارش کرد.
- ۱۳۶ بررسی گردش‌کار، ۲۳ بررسی پذیرش با ۲۵۱ پروندهٔ مصنوعی، ۵۱ بررسی API تکنسین، ۶۸ بررسی مرورگر تکنسین و ۴۶ بررسی مرورگر مرکز عملیات روی نامزد دوم دوباره موفق شدند.
- TypeScript، Build، PHP lint، ۲۸ آزمون Node و دو آزمون بسته‌بندی موفق بودند. نصب تازه و ارتقا از هر دو نسخهٔ `2.0.0-php.10` و `1.0.0-dev.3` با بررسی نسخه، سلامت، پروندهٔ قبلی و تنظیمات تأیید شد.

## 1.0.0-rc.1 — گردش کامل تعمیر در محیط آزمایشی

- ۴۲ بررسی نسخهٔ هفتم با HTTP و Chromium موفق بود. سیاست ارجاع، سقف تجمعی خرید، عدم افزایش موجودی پیش از دریافت، فاکتور پیش از کنترل کیفیت، اصلاح مجاز، دریافت QC، نسخه‌بندی چک‌لیست، گزارش عملکرد و صف مدیریت بررسی شدند.
- ۱۳۶ بررسی گردش‌کار، ۵۱ بررسی API تکنسین، ۲۳ بررسی رگرسیون پذیرش با ۲۵۱ پروندهٔ مصنوعی، ۶۸ بررسی مرورگر تکنسین و ۴۶ بررسی مرورگر مرکز عملیات موفق بودند. اجرای نهایی در مرورگر خطای JavaScript ثبت نکرد.
- TypeScript، Build، PHP lint، ۲۸ آزمون Node و ۲ آزمون بسته‌بندی موفق بودند. هشدار اندازهٔ باندل Vite باقی است.
- نصب تازه و ارتقا از `2.0.0-php.10` و `1.0.0-dev.3` روی محیط مستقل PHP/MariaDB تأیید شدند. بعد از بازبارگذاری PHP، سلامت، نسخهٔ رابط و بک‌اند، ورود، خواندن پروندهٔ قبلی و حفظ تنظیمات بررسی شدند.
- یکی از اجراهای اولیهٔ رگرسیون، تماس تأیید را در یک پروندهٔ مصنوعی ثبت کرد، چون انتظار تست مربوط به رفتار قبلی بود. تست اصلاح شد و اجرای نهایی هیچ تأیید مشتری ساختگی ثبت نکرد. هیچ پیامک واقعی ارسال نشد. استقرار، نسخهٔ پشتیبان عملیاتی و سرویس پیامک واقعی در این مرحله تأیید نشده‌اند.

## 1.0.0-dev.3 — رسید ارجاع و رسیدگی به مغایرت

- ۲۳ بررسی رگرسیون پذیرش با ۲۵۱ پروندهٔ مصنوعی موفق بود. نصب تازه از ZIP، ورود مدیر، API سلامت و فایل‌های رابط از طریق HTTP محلی بررسی شدند. ارتقا و استقرار روی هاست عملیاتی در این مرحله انجام نشد.
