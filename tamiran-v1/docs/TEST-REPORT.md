# آزمون‌های نسخهٔ توسعه

## 1.0.0-rc.1 — گردش کامل تعمیر در محیط آزمایشی

- ۴۲ بررسی نسخهٔ هفتم با HTTP و Chromium موفق بود. سیاست ارجاع، سقف تجمعی خرید، عدم افزایش موجودی پیش از دریافت، فاکتور پیش از کنترل کیفیت، اصلاح مجاز، دریافت QC، نسخه‌بندی چک‌لیست، گزارش عملکرد و صف مدیریت بررسی شدند.
- ۱۳۶ بررسی گردش‌کار، ۵۱ بررسی API تکنسین، ۲۳ بررسی رگرسیون پذیرش با ۲۵۱ پروندهٔ مصنوعی، ۶۸ بررسی مرورگر تکنسین و ۴۶ بررسی مرورگر مرکز عملیات موفق بودند. اجرای نهایی در مرورگر خطای JavaScript ثبت نکرد.
- TypeScript، Build، PHP lint، ۲۸ آزمون Node و ۲ آزمون بسته‌بندی موفق بودند. هشدار اندازهٔ باندل Vite باقی است.
- نصب تازه و ارتقا از `2.0.0-php.10` و `1.0.0-dev.3` روی محیط مستقل PHP/MariaDB تأیید شدند. بعد از بازبارگذاری PHP، سلامت، نسخهٔ رابط و بک‌اند، ورود، خواندن پروندهٔ قبلی و حفظ تنظیمات بررسی شدند.
- یکی از اجراهای اولیهٔ رگرسیون، تماس تأیید را در یک پروندهٔ مصنوعی ثبت کرد، چون انتظار تست مربوط به رفتار قبلی بود. تست اصلاح شد و اجرای نهایی هیچ تأیید مشتری ساختگی ثبت نکرد. هیچ پیامک واقعی ارسال نشد. استقرار، نسخهٔ پشتیبان عملیاتی و سرویس پیامک واقعی در این مرحله تأیید نشده‌اند.

## 1.0.0-dev.3 — رسید ارجاع و رسیدگی به مغایرت

- ۵۱ بررسی API با پروندهٔ مصنوعی موفق بود. بازبینی نسخهٔ جاری و تأیید همهٔ اقلام در سرور کنترل شدند. مغایرت باز انتقال را متوقف کرد و ثبت نتیجه توسط مدیر، مسئول پرونده را تغییر نداد.
- ۶۸ بررسی مرورگر تکنسین و ۴۵ بررسی مرورگر مرکز عملیات موفق بود. تکنسین مغایرت را از رسید ثبت کرد و مدیر از صف تحویل‌های رسمی نتیجهٔ بررسی را ثبت کرد. خطای JavaScript ثبت نشد.
- ۱۳۶ بررسی گردش‌کار، ۲۸ آزمون Node، ۲ آزمون بسته‌بندی، TypeScript، Build و بررسی نحو فایل‌های PHP تغییرکرده موفق بودند. هشدار اندازهٔ باندل Vite باقی است.
- ۲۳ بررسی رگرسیون پذیرش با ۲۵۱ پروندهٔ مصنوعی موفق بود. نصب تازه از ZIP، ورود مدیر، API سلامت و فایل‌های رابط از طریق HTTP محلی بررسی شدند. ارتقا و استقرار روی هاست عملیاتی در این مرحله انجام نشد.

## 1.0.0-dev.2 — دریافت فیزیکی دستگاه

آزمون‌ها در محیط محلی مستقل PHP 8.2 و MariaDB 10.11 با دادهٔ مصنوعی اجرا شدند.

| بررسی | نتیجه |
|---|---|
| `technician_workbench.py` | ۱۳۶ موفق، شامل دریافت صریح در Solo و Pro، تکرار درخواست و بازگشت تراکنش در صورت شکست ثبت رویداد. |
| `technician_minimal_api.py` | ۳۸ موفق، شامل کنترل مسئول پرونده، ثبت زمان و کاربر دریافت، و جلوگیری از ثبت دریافت ارجاع به‌جای تکنسین مقصد. |
| `regression.py` | ۲۳ موفق، شامل ۲۵۱ پذیرش مصنوعی و کنترل تخصیص و دامنهٔ پرونده‌ها. |
| `operations_workspace_browser.py` و `technician_minimal_browser.py` | به‌ترتیب ۴۴ و ۶۷ موفق در Chromium. کارت و دریافت در عرض‌های ۳۲۰، ۳۹۰، ۷۶۸ و ۱۴۴۰ پیکسل بررسی شدند. |
| TypeScript، Build و PHP lint | موفق. هشدار اندازهٔ باندل Vite باقی است. |
| نصب تازهٔ ZIP | موفق. نصب، ورود مدیر، سلامت API و بارگذاری CSS و JavaScript از طریق HTTP بررسی شدند. |

تغییری در Schema این مرحله لازم نبود. ارتقا روی نسخهٔ مستقر، پیامک واقعی و بررسی پس از استقرار انجام نشدند.
