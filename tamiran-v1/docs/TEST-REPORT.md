# آزمون‌های مرحلهٔ اول

مبنای نسخه `8928ffd9a3c14494e069fb0cd4d2edc7f5bb2fa6` و محیط مستقل PHP 8.2/MariaDB 10.11 با دادهٔ مصنوعی بود.

| بررسی | نتیجه |
|---|---|
| `technician_workbench.py` | ۱۲۳ موفق. شکست ثبت رویداد باعث بازگشت کامل تخصیص شد. دو درخواست هم‌زمان فقط یک مسئول ثبت کردند. ارجاع معلق پس از پایان فنی نتوانست مسئول را عوض کند. |
| `regression.py` | ۲۳ موفق، شامل ۲۵۱ پذیرش مصنوعی، جست‌وجو و همگام‌بودن مسئول. |
| `operations_workspace_browser.py` | ۴۳ موفق در Chromium، بدون خطای JavaScript. لغو ارجاع در پنل مدیر در API بازخوانی شد. |
| Build، TypeScript و نحو PHP | موفق. هشدار اندازهٔ باندل Vite باقی است. |
| Node و آزمون بسته‌بندی | ۲۹ بررسی Node و ۲ بررسی Python موفق. نصب تازه از ZIP با HTTP، ورود مدیر، سلامت API و دریافت فایل‌های JS/CSS نیز موفق بود. |

Graphify 0.9.112 ارتباط `assign` با `v2_transition`، امور مالی، تکمیل فنی و تعیین تکلیف قطعات را نشان داد. شروط تراکنش، نسخه و مجوزها از `workflow-v2.php` و `v2-core.php` بررسی شدند. گراف مستقل با Update افزایشی تازه شد. پشتیبانی AST برای SQL نصب نبود و Schema به‌صورت مستقیم با نسخه مبنا مقایسه شد. سورس پذیرش و Schema با نسخهٔ مبنا یکسان‌اند.

این نتایج مربوط به مرحلهٔ اول‌اند. تطبیق HTML، معیارهای جدید خرید/QC/مالی، آزمون ارتقای عملیاتی، SMS واقعی و آزمون پس از استقرار انجام نشده‌اند.
