# انتشار

برای `1.0.0-rc.1` یک آرشیو نصب تازه و یک آرشیو به‌روزرسانی از `2.0.0-php.10` و `1.0.0-dev.3` ساخته می‌شود. ZIP به‌روزرسانی شامل تنظیمات خصوصی، نصب‌کننده، کلید نصب و SQL نیست. مسیرهای `public_html` و `private` را به ریشه‌های متناظر منتقل کنید.

پیش از انتشار، نسخه و مسیرهای واقعی هاست را ثبت و از سورس، دیتابیس، فایل‌ها و تنظیمات در فضای خصوصی بکاپ تهیه کنید. نسخهٔ PHP، امکان بازیابی، مسیر Document Root و سلامت پس از استقرار را بررسی کنید.

در پنجرهٔ نگه‌داری، پیش از فعال‌کردن مجدد ترافیک، فایل‌ها را کامل جایگزین و PHP را مطابق امکانات هاست بازبارگذاری کنید. در `api/health.php` نسخهٔ فرانت‌اند و بک‌اند، سازگاری Schema و شناسهٔ ساخت را کنترل کنید. وضعیت بکاپ، نسخهٔ مستقر و دسترسی هاست عملیاتی هنوز تأیید نشده‌اند.
