# انتشار

بستهٔ `1.0.0-rc.11` از `1.0.0-rc.10` با فایل به‌روزرسانی و بدون Migration نصب می‌شود.

برای `1.0.0-rc.9` بستهٔ نصب و بستهٔ ارتقا از `1.0.0-rc.8` تولید می‌شود. ارتقا به Migration نیاز ندارد.

برای `1.0.0-rc.8` بستهٔ نصب تازه و بستهٔ ارتقا از `1.0.0-rc.7` تولید می‌شود. بستهٔ ارتقا به Migration نیاز ندارد و تنظیمات خصوصی، نصب‌کننده، کلید نصب و SQL را دربر نمی‌گیرد.

برای `1.0.0-rc.7` بستهٔ نصب تازه و بستهٔ ارتقا از `1.0.0-rc.6` تولید می‌شود. برای نسخه‌های قدیمی‌تر از مسیر مستند همان نسخه تا `rc.6` استفاده کنید. بستهٔ ارتقا به Migration نیاز ندارد و تنظیمات خصوصی، نصب‌کننده، کلید نصب و SQL را دربر نمی‌گیرد.

پیش از انتشار، نسخه و مسیرهای واقعی هاست را ثبت و از سورس، دیتابیس، فایل‌ها و تنظیمات در فضای خصوصی بکاپ تهیه کنید. نسخهٔ PHP، امکان بازیابی، مسیر Document Root و سلامت پس از استقرار را بررسی کنید.

در پنجرهٔ نگه‌داری، پیش از فعال‌کردن مجدد ترافیک، فایل‌ها را کامل جایگزین و PHP را مطابق امکانات هاست بازبارگذاری کنید. در `api/health.php` نسخهٔ فرانت‌اند و بک‌اند، سازگاری Schema و شناسهٔ ساخت را کنترل کنید. وضعیت بکاپ، نسخهٔ مستقر و دسترسی هاست عملیاتی هنوز تأیید نشده‌اند.
